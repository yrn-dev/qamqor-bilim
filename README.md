# Qamqor Bilim — единая инклюзивная платформа

Реальный проект, собранный из одностраничного прототипа `qamqor_bilim.html`.
11 мировых инклюзивных инструментов (Read&Write, Diffit, MagicSchool, LittleLit, Boardmaker, Glint, Cboard/Proloquo2Go и др.)
объединены в одном спокойном окне. Двуязычный интерфейс: **русский / қазақша**.

## 🌐 Демо-версия (онлайн, без установки)

Постоянная ссылка, работает в любом браузере 24/7: **https://markhashevanazerke-sketch.github.io/qamqor-bilim/**

Автономная демо-версия (GitHub Pages, без сервера): весь интерфейс доступен,
а вместо облачного ИИ — встроенные локальные ответы (адаптер «1 в 4», дробитель
задач, «Твой друг»). Данные демо хранятся в браузере посетителя. PIN родителя: **2025**
(страница: `/parent/`). Полная версия с настоящим ИИ запускается локально: см. ниже.

## Инструменты

| Инструмент | Что делает |
|---|---|
| 📚 Библиотека | 4 двуязычные книги, TTS-караоке, разбор слов, слоги, линейка чтения, режим «простой текст» |
| ✨ ИИ-адаптер «1 в 4» | Параграф из учебника → лёгкий текст (Diffit) + микро-шаги (LittleLit) + PECS-карточки + добрый тест |
| 🪜 Дробитель задач | Крупная задача → 3/5/7 маленьких спокойных шагов (уровни сложности) |
| 🗓️ План и история | Визуальное расписание «Сначала → Потом → Награда» + социальная история |
| 💬 Карточки AAC | Пиктограммы для сборки фразы + озвучка |
| 🌟 Профили | 5 профилей доступности: стандарт, дислексия/ЗПР, РАС, СДВГ, зрение/моторика |

## Архитектура

```
qamqor-bilim/
├── server/            # Бэкенд (Node.js + Express)
│   ├── index.js       # HTTP-сервер: статика + API (/api/adapter, /api/todo, /api/health)
│   ├── llm.js         # Клиент LLM (gemma4, OpenAI-совместимый chat/completions), разбор JSON с retry
│   ├── prompts.js     # Промпты: строгий JSON, мягкий инклюзивный тон, RU/KK
│   └── fallback.js    # Локальный фолбэк: если LLM недоступна, платформа работает на правилах
├── public/            # Фронтенд (статика, без build-шага)
│   ├── index.html     # разметка (точь-в-точь как в прототипе)
│   ├── css/styles.css # дизайн-токены и профили доступности (byte-identical с прототипом)
│   └── js/
│       ├── data.js    # билингвальные данные: UI-строки, книги, глоссарий, пресеты, AAC
│       └── app.js     # движок: состояние, TTS-движок, рендер, вызовы /api/*
├── scripts/           # one-shot утилиты разбора прототипа (split-prototype.js, patch-app.js)
├── .env               # секреты (LLM_API_KEY) — в .gitignore, не коммитится
└── .env.example       # шаблон для нового окружения
```

### ИИ

Нужна одна **LLM-модель** (gemma4) — через OpenAI-совместимый API.
Голос — встроенный Web Speech API браузера, иллюстрации — inline SVG, отдельные модели не требуются.

API-ключ хранится **только на сервере** (`.env`) и никогда не уходит на клиент.

### ИИ-эндпоинты

- `POST /api/adapter` — `{title, text, lang}` → `{title, simple[], steps[{icon,title,text}], pecs[{icon,word,desc}], quiz{q,options,correct}, source}`
- `POST /api/todo` — `{task, level:1|2|3, lang}` → `{steps[], source}` (3/5/7 шагов)
- `GET /api/health` — статус и модель

`source: "ai"` — ответ от gemma4; `source: "fallback"` — локальные правила (LLM недоступна / таймаут / битый JSON).

## Запуск

```bash
npm install
cp .env.example .env   # и вписать LLM_API_KEY
npm start              # http://localhost:3000
```

Разработка с автоперезапуском: `npm run dev`.
Порт — `PORT` в `.env` (по умолчанию 3000).

## Проверено

- `node --check` для всех JS-файлов
- Разметка body и head `index.html` — идентичны прототипу; `css/styles.css` — byte-identical
- Все 23 inline-обработчика (`onclick`/`onkeydown`/`oninput`) определены в JS
- Живые запросы к gemma4: `/api/adapter` (RU + KK), `/api/todo` (уровни 1/2/3 → ровно 3/5/7 шагов)
- Фолбэк при неверном ключе (HTTP 401) — оба эндпоинта отвечают локальной логикой
